Original public-domain Mutopia score and MIDI downloads.
See ../web/music/README.txt for complete credits and arrangement details.

catalog.json records the exact source files, source-page URLs, typesetter
credits, source MIDI checksums, excerpt windows, and per-part transformations.
Run node scripts/import-music.mjs from the repository root to rebuild the
browser's note data. The importer has no network or package dependencies.
Original score archives retain the typesetters’ public-domain dedications.
