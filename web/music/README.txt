Primeboard: classical library
=============================

Ten short themes and excerpts, arranged for the C3-C-sharp5 keyboard.
The underlying compositions and the selected Mutopia score editions are public
domain. Each edition's Mutopia page explicitly labels it Public Domain. The
original source files retain their typesetter credits and dedications.

These are synthesized arrangements, not recordings or complete performances of
large works. No third-party sound recordings, samples, streaming services, or
external music requests are used during playback. The application bundles all
note data. The new event encodings and arrangement/import code are provided
under this repository's MIT license; the source editions remain public domain.

   Theme from Symphony No. 9 (1824).

How the arrangements work
-------------------------
The nine additions are imported from Mutopia's score-generated MIDI files.
Original downloads are retained under music-sources/ in the repository; that
directory is not needed by the deployed app. music-sources/catalog.json records
exact excerpt boundaries in quarter-note beats, track selections, transpositions,
credits, download URLs, and SHA-256 checksums of the imported MIDI files.
The Brahms MIDI is extracted unchanged from the original retained ZIP archive.

Run node scripts/import-music.mjs to regenerate web/music/catalog.js offline.
No extra dependencies are required. The importer selects the specified parts,
clips them to the excerpt, transposes them, and moves any remaining pitches by
whole octaves into MIDI 48–73. This preserves pitch classes after transposition,
though chord voicings and spacing can differ from the original score. A short
articulation gap is added to each note. The original written durations, rests,
and ornaments otherwise come from the MIDI. Tempos are chosen for Primeboard,
not taken as claims about the composer's intended performance. MIDI pedal,
velocity dynamics, program changes, and expressive tempo changes are omitted.

Lead/upper parts contribute exponent 2; supporting parts contribute exponent 1.
An upper part can contain chords as well as melody. Simultaneous contributions
at the same key add before conversion to light, the exact prime product, and
square-root audio amplitude. Song weights stay fixed for their written duration;
the Hold step setting applies to live keyboard playing. Playback uses Web Audio's
clock for both audio and visuals.

Choose a song, then press Play. Changing songs stops and clears the previous
song, resets the position, updates the title, composer, source link, duration,
and BPM choices, and preserves the selected speed multiplier. It never autoplays.
Pause preserves the position and visual spectrum while silencing scheduled audio.
Resume continues there; Restart plays from the start. Stop/Escape clears playback.
Playing a key, loading a number, changing Sustain, or choosing a color preset
returns control to the live instrument. Leaving the window or hiding the page
pauses a song. The tempo menu changes speed relative to that song's default BPM.
