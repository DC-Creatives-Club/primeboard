Primeboard 1.3.0 brings the Linux desktop instrument up to date with the web app. Desktop releases now focus on Raspberry Pi (ARM64) and Linux PCs (x64).

## What changed since 1.0.0

- Chladni sand: a lightweight particle simulation gradually forms nodal patterns on the plate.
- Continuous resonant drive for Flat plate, Rounded cube, and Sphere: held notes build toward a steady response and decay after release. Sustain keeps the driver active; the strength readout follows the response.
- Video export renders recordings without replaying the full performance in real time.
- Improved audio startup, touch-key release handling, and keyboard labels on small displays.
- Updated explanations in How to use and The math.

The app works offline and includes the five visualizations, music library, recording and video export, and MIDI keyboard support. Updates are installed manually; saved recordings and settings remain in the app profile.

## Validation

Both Linux architectures pass all 151 application tests and package on native Linux runners. Each DEB is also installed and removed in clean Debian 12/13 and Ubuntu 22.04/24.04 containers, with checks for runtime libraries, the application launcher, and sandbox permissions. Hardware MIDI, audio latency, and installed GUI behavior still need testing on the intended Raspberry Pi and Linux computer.
